Vond drie bugs. De belangrijkste in de sorteercode:

smallest = 0 — should be smallest = i. Otherwise on iteration i > 0 you're searching the whole array again, including the already-sorted prefix. You'll end up swapping values back into the wrong place.

Prompt 3 — choose_pokemon() herschrijven in leesbare stijl
user prompt:

python
def choose_pokemon():

    for i, n in enumerate(names, 1):

deepseek:

Je versie heeft een paar foutjes:

Two problems:

n.title mist de haakjes → moet n.title() zijn. Anders print je de functie in plaats van de naam (zoiets als <built-in method title ...>).

s['hp'] en s['power'] zijn integers, die kun je niet met + aan een string plakken → moet str(...) om heen.

Hier is de werkende versie in jouw stijl:

python
def choose_pokemon():
    names = list(POKEMON.keys())
    for i, n in enumerate(names, 1):
        s = POKEMON[n]
        print(str(i) + ". " + n.title() + " | Stats: " + s['type']
              + " HP: " + str(s['hp']) + " Power: " + str(s['power']))
    while True:
        try:
            c = int(input("Kies een nummer: "))
            if 1 <= c <= len(names):
                return names[c-1]
        except ValueError:
            pass
        print("Ongeldige keuze")
Wat er veranderd is:

n.title → n.title() — anders print je de functie in plaats van de naam.

str(i), str(s['hp']), str(s['power']) — je kunt een int niet met + aan een str plakken.

while-loop toegevoegd — anders retourneert de functie None en crasht je spel zodra je een Pokémon kiest.

Alternatief: als je het str()-gedoe lelijk vindt, kun je ook komma's gebruiken in print() (die voegt automatisch spaties toe en maakt van elk argument tekst):

      "HP:", s['hp'], "Power:", s['power'])
Prompt 4 — fight() in dezelfde leesbare stijl
user prompt:

deepseek:

Hier is fight() in dezelfde leesbare stijl als je choose_pokemon:

python
def fight(p_name, p_stats, e_name, e_stats):
    p_hp = p_stats['hp']
    e_hp = e_stats['hp']

    print("\n=== " + p_name.title() + " vs " + e_name.title() + " ===")
    print("Druk op SPATIE als de groene lijn de rode raakt!")

    while p_hp > 0 and e_hp > 0:
        # jouw aanval
        dist = curses.wrapper(attack)
        dmg = max(1, p_stats['power'] - dist // 2)
        e_hp = e_hp - dmg
        if e_hp < 0:
            e_hp = 0
        print("Je raakt " + e_name.title() + " voor " + str(dmg) + "! (vijand: " + str(e_hp) + " HP)")

        if e_hp <= 0:
            print("Je versloeg " + e_name.title() + "!")
            return True

        # vijand valt aan
        edmg = random.randint(1, e_stats['power'])
        p_hp = p_hp - edmg
        if p_hp < 0:
            p_hp = 0
        print(e_name.title() + " raakt jou voor " + str(edmg) + "! (jij: " + str(p_hp) + " HP)")

    print("Je bent verslagen door " + e_name.title() + "!")
    return False
Wat er veranderd is:

Alle f"..." prints weg → nu "tekst " + str(getal) zoals jij het deed in choose_pokemon.

str() om alle getallen die je aan een string plakt (dmg, e_hp, edmg, p_hp).

e_hp -= dmg → e_hp = e_hp - dmg — iets duidelijker voor een beginner.

HP wordt niet onder 0 geprint — ik zet e_hp en p_hp op 0 als ze negatief worden, anders zie je straks "vijand: -3 HP" in beeld.

Commentaar erbij (# jouw aanval / # vijand valt aan) zodat je snel ziet welk blok wat doet.
